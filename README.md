# 手工织锦纹样排版台

直接打开 `index.html` 使用。

## 功能

- 网格绘制：点击填色，按住拖动连续填色；支持单点 / 十字 / 小菱形图章。
- **框选存块**：切到「框选模式」，在画布上拖出矩形，起名后保存为纹样块，可在「我的纹样块」里选中或删除。
- **横纵铺放**：选中纹样块，设置横向次数、纵向次数与起点（可手填 1 起的列行号，也可点「点画布取起点」后在画布上点格），按「铺放到画布」。
  - 一次铺放只记一条撤销；
  - 越界格舍去，铺放范围外的颜色不动；
  - 铺完后用色统计、重复单元预览、断线风险均按合并后的画布重算。
- 撤销 / 重做、新建网格照常可用；新建网格会清空画布但保留已保存的纹样块。
- 保存方案（localStorage）与导出 JSON 均包含画布和纹样块；导出另带各色线用量。

## 文件结构

- `index.html`：页面骨架与样式。
- `js/data.js`：数据层——画布格数据、色线库、纹样块资产、撤销重做历史、本地存取与导出组装。
- `js/rules.js`：规则层——图章落点、选框归一化、纹样截取、横纵铺放（越界裁剪）、用色统计、重复单元、断线风险。
- `js/interact.js`：交互层——DOM 渲染与事件绑定（填色、框选、存块、铺放、保存导出）。
