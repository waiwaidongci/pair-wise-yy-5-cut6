# 手工织锦纹样排版台

直接打开 `index.html` 使用。绘制经纬网格纹样，把框选区域保存为命名纹样块（回纹、万字纹等），
再按横纵次数铺放到画布任意位置，统计色线用量并保存方案。

## 文件结构（三个业务文件）

- `js/data.js` —— 数据层：画布/色线/纹样块库/撤销栈状态，以及本地 localStorage 存取。
- `js/rules.js` —— 规则层：选框归一化、纹样块捕获、铺放合并与越界裁剪、撤销快照、
  用色统计、重复单元预览、断线风险、导出数据组装。纯数据运算，不依赖 DOM。
- `js/app.js` —— 交互层：填色 / 框选存块 / 铺放三种模式的界面与指针交互。

## 用法

1. **填色**：选色线，可用单点 / 十字 / 小菱形笔刷；按住拖动连续填色，一次拖动算一次撤销。
2. **框选存块**：切到“框选存块”，在网格上拖出矩形，松手后起名（如“回纹3×3”），保存为纹样块；
   纹样块库中可预览单元、调整该块的横纵铺放次数，或删除。
3. **铺放**：点纹样块卡片上的“铺放”（或顶部“铺放”按钮），设好横纵次数，
   在画布上点击落点（以该格为纹样块左上角）；悬停时红色预显实际落点、深格为锚点。
   - 整次铺放算一次撤销；
   - 落在画布外的块格直接舍去，状态栏报告舍去格数；
   - 铺放范围外的画布颜色保持不动。
4. 铺完（或撤销/重做）后，右侧用色统计、重复单元预览、断线风险均按合并后的当前画布实时重算。
5. **保存方案**：画布与纹样块库一起写入本机浏览器，下次打开自动恢复；
   **导出JSON**：导出包含 `cols / rows / cells / blocks / usage` 的 JSON 文件。
6. 新建网格会清空画布并保留已保存的纹样块库；撤销、重做、新建、导出沿用原行为。
